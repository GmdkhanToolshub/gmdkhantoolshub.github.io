GM BI Studio

A six-step path from raw data to a report people can trust, with a guide, a practice file and a finish test for each step.

On this page

  • Where should you start?
  • 1 Organise your data
  • 2 Learn the formulas you need
  • 3 Choose and define measures
  • 4 Build the dashboard
  • 5 Make it repeatable

Where should you start?

Tick every statement that is already true for your report. Leave a box empty if you are not sure.

  1. 1 Organise your data

    One table, one row per record, consistent names, and totals left to formulas.

    Read
    Data layout in the dashboard guide
    Practise
    Look at the Data sheet in the sales dashboard example.
    Tools
    Spreadsheet Checker, PDF to Excel, Excel to PDF
    Finished when
    Someone else can add next month’s rows without asking you where they go.

  2. 2 Learn the formulas you need

    Totals, counts, lookups and error handling that you can explain.

    Read
    Excel Formula Library
    Practise
    Download the formula examples and change the sample data.
    Tools
    Excel Formula Generator
    Finished when
    You can check one result by hand and get the same answer.

  3. 3 Choose and define measures

    A few measures, each with a written definition and an action it can lead to.

    Read
    Choosing sales measures and weighted KPI scorecards
    Practise
    Sales performance example.
    Tools
    KPI Performance Calculator, Business Calculator Lab
    Finished when
    Two people calculating a measure get the same figure.

  4. 4 Build the dashboard

    One screen that answers agreed questions, with checks you can see.

    Read
    Excel dashboard guide and HR attendance dashboard guide
    Practise
    HR dashboard example or inventory example.
    Tools
    Colour Contrast Checker
    Finished when
    The totals agree with the source system and a reader can find the main point quickly.

  5. 5 Make it repeatable

    New data goes in the same way each period, and bad data is caught.

    Read
    Automated monthly reporting
    Practise
    Add a month to the monthly report example and watch its checks.
    Tools
    Business Report Generator
    Finished when
    A second person can run the month from your written steps.

  6. 6 Explain and decide

    Separate what happened, why, what may happen and what to do.

    Read
    BI vs business analytics
    Practise
    Study the Analytics sheet in the monthly report example, including the limits of its forecast.
    Tools
    Meeting Minutes Generator
    Finished when
    Each decision has an owner, and you check its result later.

Looking for a ready report instead? See the Report Library. Need one built from your data? Send your requirements.

Questions

Do I need special software?

The steps and practice files use Microsoft Excel. The ideas apply to other tools, but the files were tested only in Excel (version 16.0).

Where should I start?

Use the self-check. It points to the earliest step with a gap, because later work depends on earlier steps.

Are my self-check answers saved?

No. They stay on this page in your browser and are not sent or stored.

How long does it take?

It depends on your data and experience. Finish one small report through all six steps before building a larger one.
