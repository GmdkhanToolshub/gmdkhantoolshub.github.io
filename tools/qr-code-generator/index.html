Static and dynamic QR codes

This tool creates static QR codes, which store your content directly inside the pattern. That has clear benefits: no account, no scan limit, no expiry date and no third party in between. A code that links to a website keeps working for as long as that website does.

The trade-off is that a static code can't be edited. Change the content and you need a new code. It also has no scan tracking.

Dynamic codes from paid services point to a short link that the provider can redirect, which lets you change the destination and count scans. But they depend on that provider, and the code may stop working if the subscription or service ends.

A useful tip: for printed material, link to a page on your own website. You can then update that page at any time without reprinting the code.

Choosing an error correction level

Error correction adds spare data so a code can still be read when part of it is dirty, scratched or covered. More correction makes the pattern denser, so each square gets smaller at the same print size.

LevelDamage it can recover fromBest for
Low (L)About 7%Clean screens and long content
Medium (M)About 15%Most uses, and the default here
Quartile (Q)About 25%Packaging and items that get handled
High (H)About 30%Outdoor signs and rough surfaces

Long content needs more squares, and a QR code has a hard limit: about 2,953 bytes at Low, falling to about 1,273 at High. If the tool says your content is too long, shorten it or choose a lower level. Shorter content always scans more easily, so use a short web address where you can.

Print size and scanning distance

A widely used guideline is a 10:1 ratio: a person can scan from about ten times the width of the code. These are starting points, not guarantees, as they depend on the camera, lighting and how dense the code is:

Where it appearsTypical scan distanceSuggested code width
Business cardAbout 20 cmAt least 2 cm
Flyer or table cardAbout 30–50 cm3–5 cm
Wall posterAbout 1–2 m10–20 cm
Shop window or bannerAbout 5 m50 cm

Download SVG for print, because it stays sharp at any size. Use PNG for websites, documents and presentations. If you use PNG for print, pick the largest size available, which is 1024 pixels. Don't stretch a small image, since blurred edges make a code harder to read.

Design rules that keep a code scannable

  • Use dark on light: a dark foreground on a light background scans best. The tool warns you if contrast is low or the colours are inverted, as some readers can't read inverted codes.
  • Keep the empty border: scanners need the blank margin around the code, known as the quiet zone. The tool adds it automatically, so don't crop it or place the code tight against other artwork.
  • Be careful with logos: this tool doesn't add logos. If you place one on top yourself, use High error correction, keep the logo small and away from the three large corner squares, and test it carefully.
  • Choose matte where possible: glare on glossy or curved surfaces can stop a phone from reading the code.
  • Say what it does: add a short line such as "Scan for our menu". People are more likely to scan when they know what they will get.

Test before you print

  1. Scan it with at least two different phones, ideally one Android and one iPhone.
  2. Check it goes to the exact page or shows the exact details you intended.
  3. Print one copy at the final size and scan it from the distance people will really use.
  4. Test it in the actual lighting, particularly for outdoor or evening use.

Safety and privacy

Wi-Fi codes: your password is stored inside the code in readable form, so anyone who scans it, or takes a photo of it, can get it. Use a guest network for public places.

Contact codes: a printed vCard shares everything in it, so include only the details you are happy to make public.

Payments: this tool doesn't create payment QR codes. For Raast, bank or wallet payments, get your code from your bank or payment provider.

Scanning codes from others: fake stickers placed over real codes are a known scam. Check the web address your phone shows before you open it, and be especially careful if a page asks for a login or payment.

Frequently asked questions

Do these QR codes expire?

No. They contain the data itself, so they work as long as the destination does.

Which error correction level should I choose?

Medium suits most uses. Use High if you will print on rough surfaces or add a logo.

Can I print the SVG?

Yes. SVG scales to any size without losing sharpness, which is ideal for print.

What is the difference between static and dynamic QR codes?

A static code stores the content directly and works without any service, but it can't be edited. A dynamic code points to a redirect link run by a provider, so the destination can change, but it depends on that provider. This tool creates static codes.

What size should a printed QR code be?

A common guideline is to make the code at least one-tenth of the scanning distance, with about 2 cm as a practical minimum for business cards. Always test a printed copy at its final size.

Is it safe to put my Wi-Fi password in a QR code?

The password is stored in readable form, so anyone who scans the code can get it. For public places, use a guest network rather than your main one.
