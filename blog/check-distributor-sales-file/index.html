What to Check Before Accepting a Distributor’s Sales File

Ten checks for a distributor sales file before it enters your report, with Excel formulas and a practice file that has the problems planted in it.

By Gmd Khan Niazi (Ghulam Mohiuddin Khan Niazi)Published 27 November 20265 min read

A distributor’s file can open without any error and still be wrong for your report. A repeated line adds sales that did not happen. A line from last month moves sales into the wrong period. A product code nobody recognises disappears from the product summary. This checklist finds problems like these before the file is added to your figures.

Use the practice file to try each check. It has an invented October file, a product list, and problems planted on purpose.

Download the practice file

Excel file with made-up data. No sign-up.

Before you start

  • Keep the file exactly as received. Save a copy and work on the copy.
  • Write down what you expected: the period, the columns, whether amounts include tax and discounts, how returns are shown, and the total the distributor says the file contains.
  • Protect personal data. Keep only what the report needs, and share the file only with people who need it.

The ten checks

CheckIn the practice fileWhat to ask
1. Are all expected columns there?All eight are presentWhich column changed, and why?
2. Does the file total match the distributor’s total?The rows add to 364,320. The covering note says 345,000Which lines does your total include?
3. Are any rows repeated?Invoice D-5005 appears twiceOne sale or two?
4. Is anything missing?D-5006 has no outlet codeWhich outlet bought this?
5. Does quantity × rate equal the total?D-5007 differs by 500Discount, charge or mistake?
6. Are dates real dates inside the period?D-5008 is text; D-5013 is from SeptemberWhat date is it, and which month should it count in?
7. Are numbers stored as numbers?D-5009 has a quantity saved as textCan the export keep numbers as numbers?
8. Is every code on your list?D-5011 uses P-109, which is not listedNew product, or wrong code?
9. Are negative lines explained?D-5012 has a quantity of −6Is this a return? Against which invoice?
10. Is anything unusually large, or spelled differently?D-5014 has 90 units; “north” appears beside “North”Please confirm the quantity and use one spelling

Removing the repeated row would leave 351,070, which still does not match 345,000. Do not force the file to match. Ask the distributor which lines make up their figure.

Let the free checker do the first pass

The Spreadsheet Checker reads the file in your browser without uploading it. On the practice file it flags the repeated row, the missing outlet code, the line total, the text date, the quantity stored as text and the two spellings of North.

It does not flag the product code that is missing from your list, the negative quantity, the September date, the unusually large quantity or the difference from the covering note. It does not compare your sheet with other lists or know your period. Those checks need the formulas below and your own judgement.

Excel formulas for the other checks

In the practice file the data is on the Distributor file sheet in rows 2 to 18. Type the first day of the period in K1 and the last day in K2. Put each formula below in an empty column in row 2 and copy it down.

Product code not on your list:

=IF(ISNUMBER(MATCH(E2,'Product list'!$A$2:$A$5,0)),"","Unknown code")

Date that is text or outside the period:

=IF(NOT(ISNUMBER(B2)),"Not a real date",IF(OR(B2<$K$1,B2>$K$2),"Outside period",""))

Negative or unusually large quantity. This marks anything more than five times the middle quantity. Five is only a starting point: choose a limit that suits your products and outlets.

=IF(N(F2)<0,"Negative",IF(N(F2)>5*MEDIAN($F$2:$F$18),"Unusually large",""))

N() treats a number stored as text as zero, so fix those first. For the file total, use =SUM(H2:H18) and compare it with the distributor’s figure.

Decide what happens to a problem line

  • Accept when the check passes.
  • Hold when you need an answer. Keep it out of the totals and show how much is held.
  • Correct only with the distributor’s confirmation. Record the old value, the new value, who confirmed it and when.

Never delete a line without a record, and never type an estimate into a missing field. Report the accepted total and the held total side by side so readers can see what is still open.

Send one clear query list

Send one list with the invoice number, what you found and the question. Agree a reply date that leaves time before your report is due. If the same problem returns each month, fix the template or export with the distributor instead of correcting it again.

Frequently asked questions

Should I reject the whole file for one error?

Agree this rule in advance. Many problems can be held line by line, but a wrong period, missing columns or a total nobody can explain may justify asking for a new file.

Can one formula check everything?

No. Formulas can test rules you define. They cannot tell you whether a sale really happened.

How often should these checks run?

Run them on every file before it enters a report, using the same list each time.
