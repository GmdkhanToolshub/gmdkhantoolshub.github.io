Smart Spreadsheet Checker

Find common problems in a sales or stock sheet before you rely on its totals. It uses fixed rules, not AI, and it does not change your file.

    Request a cleanup quote

    What it looks for

    • Possible repeated rows and missing values
    • Line totals that do not equal quantity times rate
    • Mixed date styles, and numbers saved as text
    • One item, area or name written in different ways
    • Values it cannot read, plus headings, notes and empty rows inside the data

    What it cannot do

    A flag means “look at this”, not “this is wrong”. A result with no flags does not prove the figures are correct. It does not catch every spelling difference (for example “N. Market” and “North Market”, or “center” and “centre”), wrong amounts that still multiply correctly, or missing sales. If each row has its own serial number, two copies of one sale are not seen as repeats. It checks one sheet at a time, assumes one table with one heading row, and does not check hidden sheets. It is not an audit or accounting advice.

    To organise your data so these problems are less likely, start with step 1 in BI Studio.

    Questions

    Is my file uploaded?

    No. The page reads the file in your browser and does not send it anywhere. This page carries no advertising or analytics scripts, and its security policy blocks scripts from other websites and data requests made by scripts.

    Does it use AI?

    No. It follows fixed rules, so the same file and column choices give the same result.

    Does it fix my file?

    No. It lists what to look at and leaves your file unchanged. You decide what is really wrong.

    Which files work?

    Excel .xlsx and CSV files up to 5 MB, 20,000 rows and 60 columns. Old .xls files must be saved as .xlsx first. The checker was tested with CSV files and with Excel files made by Microsoft Excel and by a spreadsheet code library. Files exported from other spreadsheet programs were not tested.
